# Spring Boot Project Setup

Now we'll set up the Java Spring Boot backend that powers CloudCode. Spring Boot provides the production-grade foundation we need for our cloud IDE.

## Project Initialization

We'll use Spring Initializr to bootstrap our project:

```bash
curl https://start.spring.io/starter.zip \
  -d type=gradle-project \
  -d language=java \
  -d bootVersion=3.2.0 \
  -d groupId=com.cloudcode \
  -d artifactId=cloudcode-server \
  -d name=CloudCodeServer \
  -d packageName=com.cloudcode \
  -d javaVersion=21 \
  -d dependencies=web,websocket,data-jpa,postgresql,validation,actuator,lombok \
  -o cloudcode-server.zip

unzip cloudcode-server.zip -d cloudcode-server
cd cloudcode-server
```

## Project Structure

Here's how we'll organize our Spring Boot application:

```
cloudcode-server/
├── src/main/java/com/cloudcode/
│   ├── CloudCodeApplication.java    # Main entry point
│   ├── config/
│   │   ├── WebSocketConfig.java     # WebSocket configuration
│   │   ├── CorsConfig.java          # CORS for frontend
│   │   └── SecurityConfig.java      # Authentication
│   ├── collaboration/
│   │   ├── EditorHandler.java       # WebSocket handler
│   │   └── DocumentService.java     # Document management
│   ├── files/
│   │   ├── FileController.java      # REST API for files
│   │   ├── FileEntity.java          # JPA entity
│   │   └── FileRepository.java      # Database access
│   ├── execution/
│   │   ├── CodeExecutorService.java # Docker-based execution
│   │   └── ExecutionResult.java     # Result model
│   └── auth/
│       ├── AuthController.java      # Login/signup endpoints
│       └── JwtService.java          # Token management
├── src/main/resources/
│   ├── application.yml              # Configuration
│   └── schema.sql                   # Database schema
└── build.gradle                     # Dependencies
```

## Application Configuration

```yaml
# src/main/resources/application.yml
server:
  port: 8080

spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/cloudcode
    username: cloudcode
    password: ${DB_PASSWORD}
    hikari:
      maximum-pool-size: 10
  jpa:
    hibernate:
      ddl-auto: update
    show-sql: false
    properties:
      hibernate:
        dialect: org.hibernate.dialect.PostgreSQLDialect
        format_sql: true

app:
  jwt:
    secret: ${JWT_SECRET}
    expiration: 86400000
  cors:
    allowed-origins: http://localhost:3000
```

## Main Application Class

```java
// src/main/java/com/cloudcode/CloudCodeApplication.java
package com.cloudcode;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class CloudCodeApplication {

    public static void main(String[] args) {
        SpringApplication.run(CloudCodeApplication.class, args);
        System.out.println("""
            ╔══════════════════════════════════════╗
            ║     CloudCode Server is running!     ║
            ║     http://localhost:8080             ║
            ╚══════════════════════════════════════╝
            """);
    }
}
```
