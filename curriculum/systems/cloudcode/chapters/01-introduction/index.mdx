# Introduction to Cloudy Code

Welcome! In this system, you'll build **Cloudy Code** — a cloud-based code editor that supports real-time collaboration, containerized code execution, and a distributed file system.

## What We're Building

Cloudy Code allows developers to write, run, and collaborate on code entirely in the browser. Think of it as building your own simplified version of VS Code in the cloud.

<LanguageTabs>
  <TabItem value="typescript" label="TypeScript">
    ### Project Setup (TypeScript)

    We'll use Next.js for the frontend and NestJS for the backend:

    ```bash
    npx create-next-app@latest cloudy-code --typescript
    cd cloudy-code
    npm install @nestjs/core @nestjs/websockets socket.io
    ```

    ```typescript
    // server/src/main.ts
    import { NestFactory } from '@nestjs/core';
    import { AppModule } from './app.module';

    async function bootstrap() {
      const app = await NestFactory.create(AppModule);
      app.enableCors();
      await app.listen(3001);
      console.log('Cloudy Code server running on port 3001');
    }
    bootstrap();
    ```

      allow_origins=["*"],

## System Architecture

Here's an overview of the system we'll build:

![Architecture Diagram](/systems/cloudy-code/chapters/01-introduction/architecture.png)

The system consists of four main services:

1. **Frontend Service** — React-based code editor UI
2. **Collaboration Service** — WebSocket server for real-time editing
3. **Execution Service** — Docker-based code runner
4. **File Service** — Distributed file storage
