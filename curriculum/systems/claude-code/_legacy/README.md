# Legacy Content Archive

This directory contains files from the **old folder_tag curriculum structure**
(`architecture/`, `implementation/`, `specification/`, `tradeoffs/`, `diagrams/`,
`quizzes/`, `challenges/`).

## Why Are These Files Here?

In July 2026, the curriculum was restructured from a **content-type-based**
structure (where files were organized by type: architecture, tradeoffs, etc.)
to a **lesson-based** structure (organized by modules and learning sequences).

These old files have content that **has not yet been migrated** to the new
lesson structure. They are preserved here for reference.
