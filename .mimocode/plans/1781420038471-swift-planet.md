## What Changes

### 1. Rename `components/` → `_components/`
- Current: `src/presentation/components/` (3 files)
- Target: `src/presentation/_components/`
- Files: `components.atomic.tsx` → `components.atomic.ts`, same for composite and layout

### 2. Consolidate `_styles/` into ONE file
- Current: `_styles/` has `components/` (21 subdirs, 166 CSS files, 22K lines), `pages/` (17 items, 8K lines), `globals.css`, `ComingSoon.module.css`, `styles.components.ts`
- Target: `_styles/components.styles.ts` — ONE file containing ALL style utilities
- The 166 CSS module files and 17 page CSS files get converted to Tailwind utility functions in `components.styles.ts`
- `globals.css` stays as-is (global resets)
- All `.module.css` files and subdirectories get deleted

### 3. Move all feature folders into `features/`
- All 30+ directories currently at `src/presentation/about/`, `src/presentation/admin/`, etc. move into `src/presentation/features/`
- `contexts/` moves into `features/contexts/`

### 4. Update ALL imports
- 117 files import from `_styles/components/` → update to `_styles/components.styles`
- 24 files import from `_styles/pages/` → update to `_styles/components.styles`
- 3 component files import from `../_styles/` → update path
- All `presentation/components/` references → `_components/`
- All feature imports gain `features/` in path
