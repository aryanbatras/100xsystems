# Plan: Consolidate ALL styles into .styles.ts files

## Target Structure

```
src/presentation/_styles/
├── globals.css                    # Keep as-is (global resets)
├── components.styles.ts           # ONE file, ALL component styles
├── articles.styles.ts             # Per-feature style files
├── dashboard.styles.ts
├── groups.styles.ts
├── navbar.styles.ts
├── ... (one .styles.ts per feature)
└── [NO subdirectories]
```

## Current State
- `_styles/components/` — 143 CSS module files (22K lines)
- `_styles/pages/` — 21 CSS module files (8K lines)
- `_styles/components.styles.ts` — 65 lines (existing utility functions)
- 120+ files import from CSS modules via `styles.className`

## Conversion Pattern

CSS module:
```css
.adminContainer {
  min-height: 100vh;
  background: #ffffff;
  padding: 0;
}
```

Becomes Tailwind utility in `.styles.ts`:
```ts
import { cn } from '../../../application/lib/utils';
export const adminContainer = () => cn('min-h-screen bg-white p-0');
```
