## Problem

Find the k-th number that can be eliminated with XOR operations.

## Example

**Input:** 5  
**Output:** 10  

## Solution Approach

### Method 1: Binary representation

Build the number by bits.

## Time Complexity

O(log k)

## Space Complexity

O(1)

## Edge Cases

- k = 1: 1

- Bit manipulation
