## Problem

Maximize sum by flipping subarray.

## Example

**Input:** 5  
1 0 0 1 0  

**Output:** 4  

## Solution Approach

### Method 1: Kadane

Modify Kadane for flips.

## Time Complexity

O(n)

## Space Complexity

O(1)

## Edge Cases

## Applications

- Subarray max
