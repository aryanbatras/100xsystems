## Problem

Max magical sticks.

## Example

**Input:** 3  

**Output:** 1  

## Solution Approach

### Method 1: Divide by 2

n = int(input())

print(n // 2)

## Time Complexity

O(1) - Constant.

## Space Complexity

O(1).

## Edge Cases

- **1**: 0

- **2**: 1

- **3**: 1

- **Even**: n/2

## Applications

- **Math**: Pairs

- **Sticks**: Max
