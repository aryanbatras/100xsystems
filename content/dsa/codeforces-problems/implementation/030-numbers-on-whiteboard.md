## Problem

Min operations to make all 1.

## Example

**Input:** 3  

**Output:** 2  

## Solution Approach

### Method 1: Always Possible

# For n numbers, need n-1 operations

print(n - 1)

## Time Complexity

O(1) - Constant.

## Space Complexity

O(1).

## Edge Cases

- **n=1**: 0
- **n=2**: 1
- **Large n**: n-1

## Applications

- **Math**: Operations
- **Reduction**: To 1

## Practice Tips

- Output n-1
- Simple formula
