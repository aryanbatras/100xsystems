## Problem

Min operations from a to b.

## Example

**Input:** 4 60  

**Output:** 4  

## Solution Approach

### Method 1: Check Divisibility

a, b = map(int, input().split())

if b % a != 0:

    print(-1)

else:

    x = b // a

    count = 0

    while x % 2 == 0:

        x //= 2

        count += 1

    while x % 3 == 0:

        x //= 3

        count += 1

    if x == 1:

        print(count)

    else:

        print(-1)

## Time Complexity

O(log b) - Division.

## Space Complexity

O(1).

## Edge Cases

- **a == b**: 0

- **Not divisible**: -1

- **Only 2s**: Count

- **Only 3s**: Count

- **Mixed**: Count

## Applications

- **Math**: Factors

- **Operations**: Multiplication
