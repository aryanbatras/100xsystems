## Problem

Count paths of length k in tree.

## Example

**Input:** 5 2  
1 2  
2 3  
3 4  
4 5  
**Output:** 3  

## Solution Approach

### Method 1: Tree DP

DP for subtree paths.

## Time Complexity

O(n * k)

## Space Complexity

O(n)

## Edge Cases

- k = 1

## Applications

- Path counting
