## Problem

Count paths with cat limit.

## Example

**Input:** 4 1  
1 1 0 0  
1 2  
2 3  
3 4  
**Output:** 2  

## Solution Approach

### Method 1: DFS

DFS with cat count.

## Time Complexity

O(n)

## Space Complexity

O(n)
