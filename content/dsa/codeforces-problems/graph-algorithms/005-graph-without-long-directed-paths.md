## Problem

Assign directions without long paths.

## Example

**Input:** 3 3  
1 2  
2 3  
1 3  
**Output:** YES  
1 2 3  

## Solution Approach

### Method 1: Bipartite check

Check if bipartite for direction.

## Time Complexity

O(n + m)

## Space Complexity

O(n)

## Edge Cases

- Not bipartite

## Applications

- Graph orientation

## Practice Tips

- Bipartite coloring
