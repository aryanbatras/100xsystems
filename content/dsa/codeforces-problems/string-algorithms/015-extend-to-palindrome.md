## Problem

Extend the string to make it a palindrome by adding characters.

## Example

**Input:** aa  

**Output:** aa  

## Solution Approach

### Method 1: KMP

Find the longest prefix that is a palindrome suffix.

## Time Complexity

O(n)

## Space Complexity

O(n)

## Edge Cases

- Already palindrome

## Applications

- Palindrome construction

## Practice Tips
