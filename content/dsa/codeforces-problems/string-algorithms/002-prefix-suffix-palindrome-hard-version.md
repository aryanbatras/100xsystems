## Problem

Find the longest prefix-suffix palindrome.

## Example

**Input:** abacaba  

**Output:** 7  

## Solution Approach

### Method 1: Hashing

Use string hashing to check palindromes.

## Time Complexity

O(n log n)

## Space Complexity

O(n)
