## Problem

Count the number of palindromic substrings.

## Example

**Input:** aa  

**Output:** 3  

## Solution Approach

### Method 1: DP

dp[i][j] = 1 if s[i..j] is palindrome.

## Time Complexity

O(n^2)

## Space Complexity

O(n^2)

## Edge Cases

- All distinct

## Applications

- Palindrome counting

## Practice Tips
