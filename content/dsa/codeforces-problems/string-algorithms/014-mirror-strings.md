## Problem

Check if strings are mirrors of each other.

## Example

**Input:** ab ba  

**Output:** YES  

## Solution Approach

### Method 1: Reverse

Reverse one string and compare.

## Time Complexity

O(n)

## Space Complexity

O(n)

## Edge Cases

- Palindrome
