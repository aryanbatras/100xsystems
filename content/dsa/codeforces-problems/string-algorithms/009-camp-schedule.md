## Problem

Assign campers to tents based on preferences.

## Example

**Input:** 5  
1 0 1 0 1  
1 1 0 0 0  
**Output:** 3  

## Solution Approach

### Method 1: Count preferences

Count types and assign greedily.

## Time Complexity

O(n)

## Space Complexity

O(1)
