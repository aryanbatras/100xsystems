## Problem

Given two strings text1 and text2, return the length of their longest common subsequence. If there is no common subsequence, return 0.

## Example

**Input:** text1 = "abcde", text2 = "ace"  
**Output:** 3 ("ace")  

**Input:** text1 = "abc", text2 = "abc"  
**Output:** 3 ("abc")  

**Input:** text1 = "abc", text2 = "def"  
**Output:** 0

## Solution Approach

### Method 1: DP
1. m, n = len(text1), len(text2)
2. dp = [[0] * (n+1) for _ in range(m+1)]
3. for i in range(1, m+1):
   - for j in range(1, n+1):
     - if text1[i-1] == text2[j-1]:
       - dp[i][j] = dp[i-1][j-1] + 1
     - else:
       - dp[i][j] = max(dp[i-1][j], dp[i][j-1])
4. return dp[m][n]

## Time Complexity

O(m * n) - DP.

## Space Complexity

O(m * n) - DP table.

## Edge Cases

- **Empty strings**: 0
- **One empty**: 0
- **Identical**: Length
- **No common**: 0

## Applications

- **String Comparison**: Common subsequences
- **Dynamic Programming**: Sequence DP
- **Bioinformatics**: DNA sequences
- **Interview Questions**: Classic

## Practice Tips

- Fill DP table
- Match characters
- Max from left or up
- Optimize space to O(min(m,n))
