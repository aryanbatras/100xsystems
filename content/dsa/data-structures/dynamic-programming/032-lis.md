## Problem

Given an integer array nums, return the length of the longest strictly increasing subsequence.

## Example

**Input:** nums = [10,9,2,5,3,7,101,18]  
**Output:** 4 (2,3,7,101)  

**Input:** nums = [0,1,0,3,2,3]  
**Output:** 4 (0,1,2,3)  

**Input:** nums = [7,7,7,7,7,7,7]  
**Output:** 1

## Solution Approach

### Method 1: DP
1. if not nums: return 0
2. n = len(nums)
3. dp = [1] * n
4. for i in range(1, n):
   - for j in range(i):
     - if nums[j] < nums[i]:
       - dp[i] = max(dp[i], dp[j] + 1)
5. return max(dp)

### Method 2: Binary Search (Patience Sorting)
1. tails = []
2. for num in nums:
   - i = bisect_left(tails, num)
   - if i == len(tails):
     - tails.append(num)
   - else:
     - tails[i] = num
3. return len(tails)

## Time Complexity

O(n^2) for DP, O(n log n) for binary search.

## Space Complexity

O(n) for DP, O(n) for tails.

## Edge Cases

- **Empty array**: 0
- **Single element**: 1
- **Decreasing**: 1
- **Increasing**: n
