# Setting Up Your Development Environment

Before we start coding, let's set up a proper development environment. This ensures consistency across contributors and makes debugging much easier.

## Prerequisites

Make sure you have the following installed:

- **Git** (v2.30+)
- **Docker** (v24+)
- **Node.js** (v20+) — for frontend tooling
- A **code editor** of your choice

## Project Structure

Here's how we'll organize our monorepo:

```
cloudy-code/
├── frontend/          # React/Next.js frontend
├── collaboration/    # WebSocket collaboration server
├── executor/         # Docker-based code execution
├── file-service/     # File storage service
├── docker-compose.yml
└── README.md
```

## Docker Setup

We'll use Docker Compose to orchestrate our services:

```yaml
# docker-compose.yml
version: '3.8'

services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: cloudycode
      POSTGRES_USER: cloudy
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"

  collaboration:
    build: ./collaboration
    ports:
      - "3001:3001"
    depends_on:
      - redis

volumes:
  pgdata:
```

    We'll use `dotenv` to load these variables:
    
    ```typescript
    import { config } from 'dotenv';
    import { resolve } from 'path';

    config({ path: resolve(__dirname, '../.env.local') });

    export const env = {
      databaseUrl: process.env.DATABASE_URL!,
      redisUrl: process.env.REDIS_URL!,
      wsPort: parseInt(process.env.WS_PORT || '3001', 10),
      jwtSecret: process.env.JWT_SECRET!,
    };
    ```
  </TabItem>
  <TabItem value="java" label="Java">

    # application.properties
    spring.datasource.url=jdbc:postgresql://localhost:5432/cloudycode

## Verification

Run the following to verify your setup:

```bash
docker compose up -d
echo "Services should be running..."
curl http://localhost:3001/health
```
